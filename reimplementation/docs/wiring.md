# Wiring models and feature 1 staged geometry

The editor currently stores legacy explicit pin-pair edges (`Document.wires`), and the simulator and `.dig` codec consume only those edges. This behavior is unchanged.

`src/geometric_wiring.rs` adds an opt-in, headless integer-segment model (`Wiring::GeometricSegments`) plus a transactional `GeometricSession`. It is not yet the document's selected wiring model and is deliberately not mirrored into `Document`; consequently it is not visible or editable in the existing GUI, compiler, CLI or codec. No geometric document may be passed off as successfully compiled or saved. Integration into `Document` and explicit compiler/export refusal are follow-on work; this module currently cannot be serialized or compiled.

The staged geometry supports signed i32 points, diagonal lines, endpoint contacts, T/branch split points and exact integer collinear interval normalization. Proper interior crossings remain separate; zero-length segments, duplicate IDs, work exceeding 80,000 pair checks and more than 30,000 segments fail. Segment IDs are deterministic: unchanged source IDs are retained where possible, merged intervals choose the least contributing ID, and generated collision IDs follow the input maximum. The edit owner validates a complete candidate before history mutation, tracks undo/redo, and rejects edits while locked. Component geometry, pin anchors, and legacy routes are not part of this model.

Current limitations: the staged model's legacy migration is not implemented; it cannot validate float pin coordinates, compare logical edges or detect topology-changing conversion. Endpoint splitting is quadratic and therefore bounded by the pair-check budget. The `GeometricSession` is not the document engine's `Session`; no claim is made that it shares that session's dirty state, diagnostics, trace, or runtime lock. Integration and codec/compiler guards are outstanding.

Behavioral reference: Digital source revision `d118dce079b6b8867024d40f9b14dfa667e52106`, read-only `draw/elements/Wire.java`, `WireConsistencyChecker.java`, `WireMerger.java`, `draw/model/NetList.java` and `Net.java`. These sources establish that diagonals exist, collinear intervals merge, endpoint contacts connect and a proper interior crossing does not. New Rust implementation and tests are authored independently; no reference code, tests, fixtures or assets were copied.
