# Geometric wiring (authoritative document model)

`Document::wires` uses a geometric-only `Wiring` wrapper over integer `Segment` endpoints. There is no pin-pair connection variant, compiler adapter, export adapter, migration API, or wire-ID counter. New documents, `.dig` v2 imports, editor routes, CLI inspection, compilation and serialization all use this representation. Each segment ID is stable within the document; the engine advances its segment-ID high-water mark transactionally, including across undo. `Session::connect` is only a convenience command that creates actual routed segments between checked pin anchors; it stores no parallel logical edge.

## Connectivity and simulation

`simulation::compile` obtains pin coordinates through toolkit-neutral `pin_geometry` and resolves endpoint topology with `topology::resolve_detailed`. Only finite, exactly integral component centers in signed-i32 range and checked i32 origin/offset arithmetic are accepted. Connectivity joins equal wire endpoints and pins at those endpoints. Proper crossings, endpoint-on-interior contacts and pins in segment interiors remain disconnected unless callers explicitly split geometry. Diagonal segments are valid. Zero-length/duplicate-ID segments and over-budget work produce typed diagnostics. Wire-only nets and unused output singleton nets are retained; isolated receivers, floating receiver nets and multiple drivers are diagnosed. Feedback remains accepted by the existing staged runtime.

This remains the one-bit, single-driver component subset—not Digital `DataBus`, tri-state/high-Z/contention, memory, sequential logic, hierarchy or full Digital behavior. Import/export preserve stored geometry without normalizing or requiring successful compilation; unsupported document fields are still refused by the strict v2 codec. The bounded geometric normalization and segment edit commands remain explicit operations. Component movement/deletion leaves stored wire geometry stationary. Native pin routing, segment selection/deletion and basic editing are headless-tested; no new gesture capabilities were introduced in this cleanup.

Self-authored simulation regression fixtures encode explicit routed `Segment` endpoints from shared symbol pin geometry. Feedback, startup, trace, fanout, truth-table and CLI paths use the same geometric document representation as production. They avoid relying on coincident pins or a hidden pin-pair fallback.
