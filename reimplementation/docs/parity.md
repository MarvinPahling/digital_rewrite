# Component-editing subset

The native editor starts empty and supports Input, Output, AND, OR and NOT placement, selection, movement, deletion and snapshot undo/redo. Symbols are original, simplified labelled boxes, not Digital artwork. Positions and labels are in-memory only. There are no wires, simulation, clipboard, `.dig` import/export, or saving. This is not a milestone completion or an exhaustive feature inventory.

Evidence: headless Rust engine history and egui frame tests. Reference investigation used Digital source revision d118dce079b6b8867024d40f9b14dfa667e52106 (document and input shape) and MaterialCraft revision 4ff5af9af7371613ee37b186e03caf49ee6dbd88 (architecture and UI organization). No reference code, fixtures, tests, or assets were copied. This is not a clean-room claim. M0 licensing/reuse policy remains unresolved and blocks distribution pending owner and legal review.
